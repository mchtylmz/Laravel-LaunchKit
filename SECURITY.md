# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Laravel LaunchKit, please report it privately. Do not disclose it publicly until we have had a chance to address it.

To report a vulnerability, send an email to the project maintainer.

Include as much detail as possible:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 48 hours. We will keep you informed as we work on a fix.

Thank you for helping keep Laravel LaunchKit and its users safe.
